# 🚀 Q-FSI Content Studio

> AI Powered Financial Content Generator

Q-FSI Content Studio es una plataforma para generar automáticamente contenido financiero profesional para redes sociales.

Inicialmente genera carruseles para Instagram.

Posteriormente generará contenido para:

- Instagram
- LinkedIn
- X
- TikTok
- Blog
- Newsletter
- PDF
- Ebook

---

# Características

✅ Generación automática de carruseles

✅ Diseño institucional

✅ Hooks virales

✅ Captions

✅ Hashtags

✅ Exportación PNG

✅ Exportación PDF

✅ Exportación ZIP

✅ IA

---

# Tecnologías

- OpenAI

# Instalación

```bash
git clone https://github.com/TU_USUARIO/QFSI-Content-Studio.git

cd QFSI-Content-Studio

pip install -r requirements.txt
```

---

# Ejecutar

```bash
streamlit run app.py
```
